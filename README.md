# Evaluation of machine-learning-assisted image analysis workflow for textile microfibers released during washing

All the data presented here are a part of the research article. The aim of this study was to introduce an accessible, machine learning-based method, using *ilastik* software, to measure textile origin microplastics. 

## Requirements
The code requires *Python* and the following libraries:

- h5py
- NumPy
- Matplotlib

Install them using:
```bash
pip install h5py numpy matplotlib
```
